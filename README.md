# web-cerpen
Ruang Aksara adalah platform situs literasi cerpen proyek akhir XII RPL yang menyajikan 20 pilihan cerita dari berbagai genre seperti romantis, drama, misteri, sci-fi, hingga cerita rakyat Nusantara. Website ini dilengkapi ilustrasi tematik, mode malam, dan narasi 8 paragraf seragam untuk pengalaman membaca digital yang nyaman.
